# FilterMe

Funny camera filters — live effects and silly quotes, all in the browser.

## What it is

Open the site, allow camera access, pick a filter, and go. Processing stays on-device; no accounts and no uploads.

## Deploy

Static site: `index.html` at the repo root. Linked Vercel project: `filterme` (`filterme-six.vercel.app`).
